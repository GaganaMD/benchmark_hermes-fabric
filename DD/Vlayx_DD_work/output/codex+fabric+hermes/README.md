# Codex + Fabric + Hermes Output

This folder represents the Hermes + Fabric + Codex run of the due diligence benchmark.

The generated company report files and source-linked audit internals are intentionally not tracked in Git. Local copies may include PPTX/PDF reports, preview files, manifests, coverage files, source registers, image reviews, and Fabric synthesis files, but those remain private because they are derived from the Vlayx diligence corpus.

Public benchmark summaries are kept at the output-folder level.
