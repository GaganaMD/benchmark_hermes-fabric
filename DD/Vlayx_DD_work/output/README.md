# Due Diligence Benchmark Output Artifacts

This folder keeps benchmark-facing output artifacts from the due diligence experiment.

The generated Vlayx company diligence reports themselves are intentionally not included in the public repository. That includes PPTX/PDF report files, preview HTML, extracted text, ZIP-expanded files, and private source documents.

Some benchmark audit artifacts are included in the three run folders (`codex`, `codex+fabric`, and `codex+fabric+hermes`) so the benchmark process remains inspectable. These include manifests, coverage files, source registers, image-review files, Fabric prompts/syntheses, and contact sheets.

The excluded report files are derived from a private diligence corpus and may contain confidential business, financial, tax, contractual, employment, credential, or source-trace information. They can remain in the local working copy for private analysis, but they should not be published without a separate sanitization review.

The public repository may include benchmark-safe material from this folder, such as comparison tables, latency summaries, run artifacts, and generated benchmark images. Those artifacts describe the benchmarking process and results rather than publishing the underlying company reports.
