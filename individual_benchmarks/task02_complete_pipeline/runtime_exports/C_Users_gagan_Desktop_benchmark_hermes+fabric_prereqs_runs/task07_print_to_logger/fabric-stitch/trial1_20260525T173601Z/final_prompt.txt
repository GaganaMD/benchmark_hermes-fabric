## A) Migration Plan
- **Scope in**: Python source files under `src/` (`src/**/*.py`).
- **Scope out**: everything outside `src/`, especially `scripts/**` (explicitly untouched), plus non-Python files.
- Parse each in-scope file with Python AST and perform **semantic** detection of executable `print(...)` call sites.
- Replace only call sites that resolve to the **built-in `print`**, excluding shadowed/rebound usages.
- Preserve output behavior as closely as possible:
  - straightforward `print("x")` → `logger.info("x")`
  - multi-arg and formatting semantics handled explicitly
  - special handling for `sep`, `end`, `file`, `flush`
- Inject logger setup only where needed and only once:
  - `import logging` (if missing)
  - `logger = logging.getLogger(__name__)` (if no module logger exists)
- Keep edits minimal and localized; avoid churn in unrelated code.
- Validate with structural/path checks, compile checks, and tests/lint.

## B) Rewrite Rules (Deterministic)
1. **Eligible file rule**
   - Only transform files matching `src/**/*.py`.
   - Never transform `scripts/**` or any other path.

2. **Eligible call rule (built-in `print`)**
   - Candidate node: `ast.Call` with `func=ast.Name(id="print")`.
   - Exclude if `print` is shadowed in reachable scope:
     - assignment/aug-assignment/annotated assignment to `print`
     - `def print(...):`, `class print:`
     - import aliasing to `print` (`import x as print`, `from x import y as print`)
     - parameter named `print`
     - comprehension/lambda/local scopes rebinding `print`
   - Exclude attribute calls like `obj.print(...)` (non-built-in by definition).

3. **Basic rewrite**
   - `print("x")` → `logger.info("x")`
   - `print()` → `logger.info("")` (nearest behavior for newline-only output in logging context).

4. **Multiple positional args (`print(a, b, c)`)**
   - Preserve default separator `' '` by constructing a joined string:
     - `logger.info("%s %s %s", a, b, c)` is preferred for lazy formatting and lint-friendliness.
   - If `sep` is explicit and valid:
     - constant/string sep: `logger.info(sep.join(map(str, [a,b,c])))` equivalent form
     - more logging-native alternative: template with separator-expanded `%s`.
   - Deterministic preference:
     - If `sep` absent or literal `' '`: `logger.info("%s %s ...", args...)`
     - Else: `logger.info("%s", sep_expr.join(map(str, args_tuple)))`

5. **`end=` handling**
   - Logging always appends record terminator at handler level; exact terminal newline behavior cannot be perfectly preserved.
   - If `end` is default `"\n"` or omitted: normal rewrite.
   - If non-default `end`:
     - preserve content by appending to rendered message before logging:
       - e.g., `print("x", end="!")` → `logger.info("%s", "x" + "!")`
       - for multi-arg, append `end` after join.
   - Note residual difference: logging record framing may still add newline.

6. **`file=` handling**
   - `print(..., file=...)` targets arbitrary streams; `logger.info` does not.
   - Fallback policy (safe/minimal):
     - **Do not rewrite** calls with explicit `file=` unless `file` is clearly `sys.stdout`/`sys.stderr` and project logger is configured equivalently.
   - Record as risk/manual follow-up.

7. **`flush=` handling**
   - `print(..., flush=True)` has direct stream flush semantics unavailable in standard `logger.info`.
   - Fallback policy:
     - If `flush` present, **do not rewrite** automatically (or rewrite only when `flush=False` and no `file=`).
   - Record as risk/manual follow-up.

8. **Comments/strings/docstrings safety**
   - No text-based replacement. AST transformation only on executable call nodes.
   - Therefore literal/documentation occurrences of `print(` remain unchanged.

9. **Idempotency**
   - Already-migrated `logger.info(...)` calls remain unchanged.
   - Logger imports/setup are injected only if absent.

# 2) AST-based check for remaining built-in print calls in src/
python - <<'PY'
import ast, pathlib, sys

def has_shadow(scope_node):
    shadow=set()
    class V(ast.NodeVisitor):
        def visit_Assign(self,n):
            for t in n.targets:
                if isinstance(t, ast.Name) and t.id=="print": shadow.add(("assign", n.lineno))
            self.generic_visit(n)
        visit_AnnAssign=visit_AugAssign=visit_Assign
        def visit_FunctionDef(self,n):
            if n.name=="print": shadow.add(("func", n.lineno))
            for a in n.args.args+n.args.kwonlyargs:
                if a.arg=="print": shadow.add(("arg", n.lineno))
            if n.args.vararg and n.args.vararg.arg=="print": shadow.add(("arg", n.lineno))
            if n.args.kwarg and n.args.kwarg.arg=="print": shadow.add(("arg", n.lineno))
            self.generic_visit(n)
        visit_AsyncFunctionDef=visit_FunctionDef
        def visit_ClassDef(self,n):
            if n.name=="print": shadow.add(("class", n.lineno))
            self.generic_visit(n)
        def visit_Import(self,n):
            for a in n.names:
                if a.asname=="print": shadow.add(("import", n.lineno))
        def visit_ImportFrom(self,n):
            for a in n.names:
                if a.asname=="print" or (a.asname is None and a.name=="print"):
                    shadow.add(("importfrom", n.lineno))
    V().visit(scope_node)
    return shadow

bad=[]
for p in pathlib.Path("src").rglob("*.py"):
    tree=ast.parse(p.read_text(encoding="utf-8"))
    # lightweight file-level shadow detection; production tool should be scope-aware
    shadow = bool(has_shadow(tree))
    for n in ast.walk(tree):
        if isinstance(n, ast.Call) and isinstance(n.func, ast.Name) and n.func.id=="print":
            if not shadow:
                bad.append((str(p), n.lineno))
if bad:
    print("Remaining potential built-in print calls:")
    for b in bad: print(*b)
    sys.exit(1)
print("No obvious remaining built-in print calls.")
PY
